# 錄音說明

多謝你幫手!呢批錄音係用嚟**測試**一個電話客服語音系統,睇下佢聽唔聽得明
「你係唔係同佢講嘢」同埋「你嘅語氣係問緊定係確認緊」。成個過程大約 **30–40 分鐘**。

## 準備
- 用**你自己部手機**錄,好似平時講電話咁拎住部機,用手機自帶嘅錄音 App 就得。
- 喺**你屋企**錄。**B 部分**最好有一位屋企人或者朋友喺同一間房(離你 1–2 米),方便你真係轉頭同佢講嘢。
- 唔使刻意搵好靜嘅地方,平時屋企嘅背景聲冇問題。
- 開始前打開你嘅**錄音清單**(`spkXX_錄音清單.md`),跟住上面嘅次序讀。

## 點樣錄
- **每個部分錄一個檔案**:A、B、C 各一個(即係一共三個檔案)。
- 每句之間**停大約 2 秒**,我哋之後會按停頓切開。
- 讀錯咗唔緊要:**停 3 秒,講「重錄」,再讀返嗰句**就得,唔使由頭嚟過。
- 檔名:`你嘅編號_A.m4a`、`你嘅編號_B.m4a`、`你嘅編號_C.m4a`(例如 `spk01_A.m4a`)。

## A 部分:語氣(約 60 句)
每張卡有一句「客服啱啱講嘅嘢」,你要**重複入面標咗嘅部分**,每張卡讀兩次:
- **【質疑】**:好似唔信、想佢再確認咁講,例如「四百蚊?」(尾音自然向上)
- **【確認】**:平平哋、表示收到咁講,例如「四百蚊。」
- ⚠️ **只講嗰個數/嗰幾個字,唔好加「呀、咩、嘛、吓、係咪」之類嘅語氣詞。**
- 質疑同確認嘅次序已經喺清單度打亂咗,跟住清單讀就得。

## B 部分:同邊個講(約 50 句)
- **【對手機】**:好似同電話另一邊嘅客服講嘢咁,對住手機講。
- **【轉頭】**:**轉頭望住房入面嘅人**,用平時叫屋企人嘅聲量同佢講。手機保持喺原本位置,唔好移。
- 有 10 句係**同一句話講兩次**:先【對手機】講一次,再【轉頭】講一次。
- 句子可以用你自己習慣嘅講法少少改,但意思唔好變。

## C 部分:自然回應(約 3 分鐘)
- **一定要戴耳機**,播 `04_C_客服講解.mp3`(**唔好外放**,否則會錄埋客服把聲)。
- 當自己真係喺度聽客服講嘢,**好自然咁回應**,例如「嗯」、「係」、「OK」、「明白」、「哦」,平時點講就點講,冇指定台詞,唔使刻意多講。
- 由開始播放到播完,錄一個檔案。

## 交返
三個檔案 + 簽好嘅同意書,交返俾聯絡人。唔該晒!
